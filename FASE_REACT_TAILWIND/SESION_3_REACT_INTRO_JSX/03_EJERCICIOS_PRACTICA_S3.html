Ejercicios de Práctica — Componentes y JSX

SENA ADSO · Ficha 3293992 · Noviembre 2026

Estos ejercicios son opcionales, para reforzar lo aprendido en 02_GUIA_COMPONENTES_JSX_S3.html si sobra tiempo en la sesión. No introducen conceptos nuevos: hazlos solo después de terminar la guía.
¿Qué practicamos aquí?
El mismo patrón de la guía, aplicado a un segundo componente

En la guía 02 separaste el navbar en Navbar.jsx. Aquí repites exactamente el mismo proceso (crear archivo → función → export default → import → usar como etiqueta), esta vez con el <footer>, para que el patrón te quede automático. Al final, un mini reto para detectar errores típicos de JSX.

Ejercicio 1
Crear src/Footer.jsx con el footer movido desde App.jsx
Ejercicios 2 y 3
Exportarlo, importarlo y dejar App.jsx ensamblando Navbar y Footer
Ejercicio 4
Encontrar el error en 4 fragmentos de JSX
Ejercicio 1

Crear src/Footer.jsx

10 min

Mismo primer paso que con el navbar: crear el archivo y mover el bloque <footer>...</footer> de App.jsx hacia adentro de una función.

1

Crea el archivo src/Footer.jsx (al lado de App.jsx y Navbar.jsx), con mayúscula inicial.

2

En App.jsx, corta (Ctrl + X) el bloque completo <footer>...</footer> y pégalo (Ctrl + V) dentro de Footer.jsx:

Bloque que se mueve de App.jsx a Footer.jsxcortar y pegar
<footer className="flex flex-col md:flex-row justify-between items-center gap-2 md:gap-0 p-6 bg-texto text-white">
  <p>© 2026 TechStore Pro</p>
  <p className="text-sm">Hecho con Tailwind CSS</p>
</footer>
Si tu footer quedó distinto (por ejemplo sin el flex-col md:flex-row del Ejercicio 3 de la Sesión 2), mueve el tuyo real.
3

Envuelve ese bloque en una función llamada Footer:

frontend-react/src/Footer.jsxcontenido (sin export todavía)
function Footer() {
  return (
    <footer className="flex flex-col md:flex-row justify-between items-center gap-2 md:gap-0 p-6 bg-texto text-white">
      <p>© 2026 TechStore Pro</p>
      <p className="text-sm">Hecho con Tailwind CSS</p>
    </footer>
  );
}
ParteQué es
function Footer()Declara el componente — nombre con mayúscula, sin datos de entrada por ahora
return ( ... );Entrega el JSX del footer cuando React llama a la función
<footer> ... </footer>El único elemento raíz: los dos <p> van adentro, no sueltos
Formatea el archivo con Shift + Alt + F si la indentación queda desordenada al pegar.
Cómo verificar: el archivo Footer.jsx existe, con la función Footer y el JSX del footer adentro — todavía sin export default: eso es el Ejercicio 2.
Ejercicio 2

export default e import

5 min

Exactamente el mismo mecanismo de los Pasos 2 y 3 de la guía. Intenta escribir cada línea antes de mirar el código.

1

Al final de Footer.jsx, agrega la línea que lo exporta como default — con el mismo formato que usaste en Navbar.jsx:

frontend-react/src/Footer.jsxagregar al final
export default Footer;
TrozoQué significa
export default"Esto es lo principal que entrega este archivo" — solo uno por archivo
FooterDebe coincidir exactamente con function Footer() — mismas mayúsculas
2

En App.jsx, justo debajo del import Navbar from './Navbar.jsx'; que ya existe, agrega una segunda línea de import para Footer:

frontend-react/src/App.jsxagregar
import Navbar from './Navbar.jsx';
import Footer from './Footer.jsx';

function App() {
  ...
TrozoQué significa
import FooterTrae lo que Footer.jsx exportó por default y lo llama Footer en este archivo
from './Footer.jsx'Ruta al archivo, en la misma carpeta src/
Una línea por componenteCada componente que uses se importa en su propia línea; el orden entre imports no importa
Cómo verificar: ni Footer.jsx ni App.jsx muestran líneas rojas en VS Code. El import está listo para usarse en el Ejercicio 3 (VS Code puede marcarlo en gris como "sin usar" hasta entonces).
Ejercicio 3

App.jsx ensamblando 2 componentes

5 min

Último paso: escribir <Footer /> en el espacio que quedó vacío al cortar el footer.

1

Dentro del return (...) de App.jsx, después del </section> del catálogo y antes de </main> — donde estaba el <footer> — escribe:

frontend-react/src/App.jsxescribir en el espacio vacío
<Footer />

App.jsx completo queda ensamblando ambos componentes:

frontend-react/src/App.jsxcómo queda
import Navbar from './Navbar.jsx';
import Footer from './Footer.jsx';

function App() {
  return (
    <main className="max-w-6xl mx-auto px-6 py-10 flex flex-col gap-10">
      <Navbar />

      <section className="grid grid-cols-1 sm:grid-cols-2 md:grid-cols-2 lg:grid-cols-3 gap-6">
        {/* Tarjetas 1 a 4 — sin cambios */}
      </section>

      <Footer />
    </main>
  );
}

export default App;
LíneaQué hace
import Navbar / import FooterTraen los dos componentes desde sus archivos
<Navbar />Dibuja el navbar (lo que devuelve la función Navbar)
<section> ... </section>El catálogo sigue escrito aquí — se componentiza en la Sesión 4
<Footer />Dibuja el footer (lo que devuelve la función Footer)
Cómo verificar: en localhost:5173 el footer se ve exactamente igual que antes, también en celular (textos apilados). App.jsx ya no tiene ni <nav> ni <footer> escritos directamente: solo los usa como <Navbar /> y <Footer />.
Ejercicio 4

Encuentra el error

10 min

Cada fragmento tiene un error que rompe una regla de JSX o de componentes vista en la apertura. Piensa la respuesta antes de abrir la solución. No hace falta escribir nada en tu proyecto.

Fragmento A
function Footer() {
  return (
    <p>© 2026 TechStore Pro</p>
    <p>Hecho con Tailwind CSS</p>
  );
}
Ver la respuesta

Hay dos elementos sueltos en el return. JSX exige un solo elemento raíz: los dos <p> deben ir dentro de un <footer> (o de un fragment <>...</>).

Fragmento B
<div class="text-xl font-extrabold text-primario">
  TechStore Pro
</div>
Ver la respuesta

En JSX se escribe className, no class: class es una palabra reservada de JavaScript. React lo detecta y muestra en la consola la advertencia Invalid DOM property `class`. Did you mean `className`?. La regla de JSX es usar siempre className.

Fragmento C
function navbar() {
  return <nav>...</nav>;
}

export default navbar;

// en App.jsx:  <navbar />
Ver la respuesta

El componente empieza con minúscula. React interpreta <navbar /> como una etiqueta HTML desconocida y no ejecuta la función: el navbar no aparece y la consola avisa que la etiqueta <navbar> no es reconocida. Debe llamarse Navbar y usarse como <Navbar />.

Fragmento D
<img src="https://placehold.co/300x200" className="rounded-lg">
Ver la respuesta

La etiqueta <img> no está cerrada. En HTML el navegador lo perdona, pero en JSX es un error de sintaxis: se escribe <img ... />, igual que en tus tarjetas del catálogo.

Recordatorio: Footer.jsx es de práctica — puedes dejarlo en el proyecto; no afecta el entregable obligatorio de la guía 02 (Navbar.jsx).
